## Image Recommendations

### Profile Photos
- High resolution (min 600x600px)
- Professional headshot
- Clear face visible
- Good lighting

### Slideshow/Background Images
- Wide format (16:9 or similar)
- High quality
- Professional settings
- Business environments

### Gallery Images
- Various aspect ratios for masonry layout
- Good quality
- Relevant to categories

## Image Optimization

For better performance:
- Compress images using tools like TinyPNG
- Use WebP format when possible
- Keep file sizes under 500KB for gallery images
- Profile images under 200KB
